## 触发条件（何时使用此 Skill）

当用户请求涉及以下场景时，应使用本 Skill：
- 查询实时信息、最新新闻、近期事件（训练数据截止后发生的事）
- 搜索特定网页内容、资料、文档、教程
- 需要获取互联网上的最新数据来回答问题
- 用户明确要求"搜索"、"查一下"、"帮我找"等

**注意**：纯知识问答、代码编写、文件操作等不需要联网的场景，不要使用此 Skill。

---

## 功能概述

本技能采用两阶段搜索模式，将「搜索」和「加载」解耦，便于逐个评估结果质量：

| 阶段 | 脚本 | 功能 |
|------|------|------|
| 第一阶段 | `scripts/do_search.py` | 执行百度搜索，返回摘要列表并缓存结果 |
| 第二阶段 | `scripts/fetch_page.py` | 根据缓存或直接 URL 获取网页清洗后的正文 |

### 输入输出 Schema

**搜索阶段输入：**
- `query`（string）：搜索关键词，建议 2-5 个核心词
- `max_results`（int）：期望返回结果数，建议 3-10

**搜索阶段输出（JSON）：**
- `session_id`（string）：格式如 `a1b2c3d4-xxxx-xxxx-xxxx-xxxxxxxxxxxx`，有效期 30 分钟
- `results`（array）：每条包含 `title`（标题）、`href`（链接）、`body`（摘要，约 100-200 字）

**加载阶段输出（在搜索结果基础上增加）：**
- `full_content`（string）：清洗后的网页正文，最长 15000 字符；失败时返回 `[无法获取内容: ...]` 等错误信息

## 调用方式（重要）

调用 `run_command` 执行本 skill 包内脚本时，**必须同时传 `skill_id="9"` 参数**。
命令中的脚本路径写相对 skill 包目录的路径（如 `scripts/do_search.py`），**不要**拼 `Skills\baiduSearch\scripts\...` 这种绝对前缀。

**⚠️ 重要：关键词参数必须用引号包裹！** 脚本已升级为智能参数解析，即使引号被 shell 吞掉也能自动拼接关键词，但最佳实践仍然是用引号包裹。

**正确调用示例：**
```
run_command(
  command="python scripts/do_search.py search \"关键词\" 5",
  skill_id="9"
)
```

### 搜索脚本（do_search.py）

**执行搜索，返回摘要列表和 session_id**
```
python scripts/do_search.py search "{query}" {max_results}
```

> 💡 **v2.1 更新**：脚本现在支持智能参数解析。即使关键词包含空格且引号被 shell 吞掉，脚本也会自动将 action 之后、最后一个数字之前的所有参数拼接为 query。例如：
> - `python scripts/do_search.py search A股 大盘 今日 8` → query="A股 大盘 今日", max_results=8
> - `python scripts/do_search.py search "A股 大盘 今日" 8` → 同上（推荐写法）

**查看所有有效会话**
```
python scripts/do_search.py list
```

### 加载脚本（fetch_page.py）

**根据 session 和索引加载指定网页详情**
```
python scripts/fetch_page.py fetch {session_id} {result_index}
```

**自动加载下一个未详查的网页**
```
python scripts/fetch_page.py next {session_id}
```

**直接加载任意 URL 的详情**
```
python scripts/fetch_page.py url "{网址}"
```

> 💡 **v2.1 更新**：fetch 和 url 命令也支持智能参数解析，URL 中的空格会被自动拼接。

## 信息不足时的补救策略

### 情况A：网页加载失败
当 `full_content` 返回以下任意一种失败信息时：
- `[无法获取内容: ...]`（如 403 禁止访问、超时等）
- `[页面内容为空]`
- `[无有效链接]`
- 内容极短（少于 50 字）

**应对方案（按顺序尝试）：**
1. 尝试同 session 中的下一个结果：`fetch_page.py next {session_id}`
2. 换一组关键词重新搜索：`do_search.py search {新关键词} {数量}`
3. 直接加载已知优质 URL：`fetch_page.py url {网址}`

### 情况B：搜索结果质量低
当搜索返回的结果标题和摘要与需求不匹配时：
1. 换关键词重新搜索：使用更精准或更宽泛的关键词
2. 直接加载已知优质 URL

### 终止条件（重要！）
- **连续 2 次换关键词搜索后仍无有效结果** → 停止搜索，调用 `finish` 告知用户搜索困难，并建议用户提供更精确的关键词或直接提供 URL
- **同 session 内所有结果全部加载失败** → 换关键词重新搜索，而非无限循环 next

## 搜索关键词优化技巧

- 使用 **2-5 个核心关键词**，避免过长句子
- 使用 **引号 ""** 进行精确匹配，如 `"AI Agent" 发展`
- 使用 **site:域名** 限定搜索范围，如 `site:zhihu.com AI Agent`
- 使用 **-关键词** 排除无关内容，如 `苹果 -水果`
- **中英文混合**关键词有时效果更好，如 `LLM 大模型 应用`
- 搜索新闻类信息可加时间限定词，如 `2024 2025`

## 常见问题 FAQ

**Q：session_id 过期了怎么办？**
A：session_id 有效期为 30 分钟。过期后需重新执行搜索获取新 session。

**Q：搜索结果全是广告怎么办？**
A：在搜索词中加 `-广告` 排除，或换用更具体的长尾关键词。

**Q：某些网站反爬导致加载失败？**
A：这是正常现象，跳过该结果尝试下一个即可。知名站点（如知乎、CSDN）通常可正常加载。

**Q：为什么建议逐个加载而不是一次性全部加载？**
A：逐个加载可以边看边判断信息是否足够，避免浪费 token 和时间。

## 注意事项

- 搜索缓存有效期为 30 分钟，超时后 session_id 失效，需要重新搜索
- result_index 从 0 开始，不能超过结果总数减 1
- 调用 run_command 时**必须**传 `skill_id="9"` 参数，否则脚本路径无法正确解析
- **执行完成后必须调用 finish 工具，将搜索结果整理后返回给用户**
- **重要：不要一次性加载所有网页，应该逐个加载、逐个理解总结**
- **连续 2 次换关键词搜索无果后，必须停止并向用户说明情况**
