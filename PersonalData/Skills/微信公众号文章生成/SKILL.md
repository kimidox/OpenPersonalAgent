## 执行流程

1. **确认主题**：检查用户是否已提供文章主题
   - 若未提供，主动询问用户想要生成的文章主题
   - 若已提供，继续执行后续流程

2. **内容扩展**：根据主题进行内容扩展
   - 分析主题的核心要点
   - 构建文章框架（3-5个主要部分）
   - 为每个部分填充具体内容

3. **生成文章**：按照标准格式生成完整文章

4. **输出结果**：将生成的文章内容直接返回给用户

## 文章结构要求

### 1. 标题
- 简洁有力，吸引读者注意
- 长度建议10-20个字符
- 可使用数字、疑问句、热点词汇增强吸引力

### 2. 开头（100-200字）
- 用故事、数据或问题引入主题
- 说明文章的价值和阅读意义
- 引发读者继续阅读的兴趣

### 3. 正文（1200-1500字）
- 分为3-5个小节，每节配小标题
- 每小节200-400字
- 内容包含：
  - 核心观点阐述
  - 案例或数据支撑
  - 实用建议或方法
- 适当使用列表、引用等格式增强可读性

### 4. 结尾（100-150字）
- 总结全文核心要点
- 给出行动建议或思考问题
- 引导读者互动（点赞、评论、转发）

## 写作风格

- **语言**：中文（简体）
- **语气**：亲切、专业、易读
- **视角**：第二人称（与读者对话）或第三人称
- **格式**：使用Markdown格式，便于排版

## 内容扩展技巧

当用户给出主题后，按以下方式扩展：

1. **背景引入**：为什么这个话题重要？
2. **现状分析**：当前存在什么问题或现象？
3. **核心方法**：给出3-5个解决方案或要点
4. **案例说明**：用具体例子增强说服力
5. **实践建议**：读者可以立即采取的行动
6. **总结升华**：提炼核心价值

## 输出格式

```markdown
# [文章标题]

[开头段落]

## 一、[小标题1]
[内容]

## 二、[小标题2]
[内容]

## 三、[小标题3]
[内容]

---

## 写在最后

[总结和行动号召]
```

## 字数控制

- **总字数**：1500-2000字（严格不超过2000字）
- **开头**：100-200字
- **正文**：1200-1500字
- **结尾**：100-150字

## 质量检查清单

生成文章前确保：
- [ ] 字数在规定范围内
- [ ] 标题吸引人且与内容相关
- [ ] 结构清晰，层次分明
- [ ] 内容有价值，可读性强
- [ ] 语言流畅自然
- [ ] 包含实用的建议或信息
- [ ] 结尾有明确的行动号召

## 注意事项

- 避免敏感话题和违规内容
- 不使用夸张或虚假宣传
- 保持内容原创性
- 适当使用emoji增强视觉效果（但不过度）
- 如主题过于宽泛，可主动询问用户具体方向
